# 画廊与《鹿王本生》配乐、归卷

首页新增《展卷听风》，第三卷五折依次使用《鹿渡清流》《岸畔一诺》《殿影生波》《车行远山》《鹿鸣归壁》。旋律由本项目新编，采用五声音阶与筝、笛意象；音色由浏览器 Web Audio 实时合成，没有引入第三方录音或采样。它们是当代配乐，不是历史古曲或北魏音乐的复原。

首页默认音量 22%，第三卷默认 26%，并有伴奏电平上限。首次访问需要点击或键盘操作后才能启动首页音乐；第三卷点击入画启动。右上角的配乐按钮可开关、调音量，两个场景分别保存偏好。阅读画卷介绍、释文或终章时自动降低音量；暂停、切后台和退出时停止播放，归卷后首页音乐按原偏好恢复。

第三卷五折的六类色层全部显现后，常驻完成提示提供“读终章 · 归卷”。终章展示原壁画全景和本项目创作的简短余音，可返回画廊、继续看壁画或打开全画释文。全画释文末尾也提供归卷按钮；关闭自动释文不影响这些入口。弹窗期间禁用底层敷彩快捷键，键盘焦点留在弹窗内。

实现复用 `src/audio/SceneMusic.js` 的播放、淡入淡出、暂停、释放和偏好存储，以及 `InkInstruments.js` 的筝笛音色。第二卷原有乐谱、默认音量和存储键保持不变。

验证：`npm test` 检查乐谱范围、笛声换气和循环余地、重复访问，以及弹窗/音量输入期间的快捷键隔离；`npm run build` 验证生产打包。浏览器核验包含五折换曲、静音记忆、阅读降音、暂停与后台停止、终章归卷、前后场景声音释放和手机布局，并回归第二卷的配乐生命周期。
