# 画中奇谭 · Beyond the Scroll

以中国传统绘画与石窟壁画为舞台的沉浸式文化体验：**入画 — 探索 — 归卷**。

当前进度：
- **卷轴入口**：三轴陈列 → 点击展卷 → 画作介绍
- **画境一 ·《江山秋色图》**：第一人称 2.5D/3D 可游览场景（介绍页点「入画」进入，或直接访问 `/#jiangshan`）
- **画境二 ·《韩熙载夜宴图》**：五折剧情导览（先展原画再入景、17 处固定视点、完整纸偶姿态轮播、靠近人物浮现情境对白、五折解谜、人物笺与卷后结局；`/#hanxizai` 直达）
- **画境三 ·《鹿王本生》**（莫高窟第257窟 北魏）：**参与式敷彩**——观众亲手为褪色的壁画敷上矿物色，逐折复原。含第257窟洞窟空间（中心塔柱、人字披、千佛列、天宫伎乐、药叉，均为程序化生成）、五折导览与「释文与依据」面板（释文逐字引自敦煌研究院网站并逐条标注）；`/#fuwang` 直达

## 评审体验：免安装启动

Windows 10 / 11 评审电脑无需配置开发环境：**将评审版 ZIP 全部解压 → 双击「画中奇谭.exe」→ 在自动打开的浏览器中选择画卷、点击「入画」**。推荐使用电脑自带的 Edge 或已安装的 Chrome。三幅画卷、字体和音乐随包携带，主体可以离线体验，文献出处中的外部链接需要联网。

体验期间保留启动器窗口，结束时点击「结束体验」或关闭启动器，再关闭浏览器页面即可。请完整解压后运行，保留启动器与 `app` 文件夹的相对位置。

开发者在 Windows 上制作评审包：安装 Node.js 22.12+（或更高版本的 LTS），在项目根目录依次执行 `npm ci`、`npm run package:windows`。成品 ZIP 和 SHA256 校验文件输出到 `release/`；该目录不提交到 Git，将 ZIP 直接交给评委即可。打包会自动构建网页，使用 Windows 自带的 .NET Framework 编译器生成启动器，不需要额外安装编译 SDK。每次打包生成独立目录，不覆盖已有评审包。

启动器仅监听本机 `127.0.0.1`，自动选择空闲端口，重复打开同一份作品会复用已有启动器，关闭后释放服务。`npm run test:launcher` 验证静态资源、音频分段请求、路径约束和服务关闭；开发诊断可使用 `画中奇谭.exe --verify <地址输出文件>`，打开真实启动器并输出本地地址，但不自动打开浏览器。

## 开发运行

```bash
npm install
npm run dev      # 本地开发 http://localhost:5173
npm test         # 素材完整性、动作循环、固定路线、切幕与家具间距回归
npm run build    # 打包到 dist/
npm run preview  # 预览打包结果
```

## 替换 / 新增画作

1. 把竖幅图片放到 `public/paintings/<id>/`
2. 在 `src/data/paintings.js` 中填写 `image.src` 与图片像素宽高，设 `available: true`
3. 卷轴会按图片比例自动计算装裱尺寸；如需调整天头、地头比例，配置 `mount`

## 卷二 · 画意与皮影

每折先展示对应原画，点击入席后淡入 Three.js 场景。点「走近 / 回看」或按 `↑ ↓` / `W S`，沿固定的席前路线移动；镜头保持在纸偶画面正侧。`1—5` 换折时重新展原画，`R` 回看当前原卷，`Esc` 暂停。靠近人物后出现动作说明和可续读的悬浮对白。

保留举杯与蓝衣舞者动作，新增拨弦、击鼓、摇扇、净手、拊掌、横笛、送别与应答姿态。角色采用对齐的完整姿态帧，取消引起衣纹与乐器扭曲的网格蒙皮；击鼓人物和鼓共用画面，落槌帧直接接触鼓面。旁观者只作轻微整片倾动，镜头移动带来受限的纸面余颤。支持系统的「减少动态效果」。

画面解读依据[故宫藏品介绍](https://www.dpm.org.cn/collection/paint/228200.html)和[故宫长卷叙事介绍](https://www.dpm.org.cn/classify_detail/180639.html)，悬浮对白明确标为情境创作，并非史料原话。当前为五折固定路线，配有可跳过、可改选的线索判断；进度保存在当前标签页，刷新后仍可续读。

场景以原作的屏风、围榻和帐床组织空间。画中没有完整墙顶或建筑平面，因此留白与行走尺度属于艺术转译，不作南唐宅第复原的声明。详细核对、素材与验证说明见 [卷二改造说明](docs/hanxizai-art-direction.md)。

`panorama-detail.jpg` 为同一 Wikimedia Commons 原文件（13,898 × 1,200）；既有 `panorama.jpg` 保持不变。人物保留以 5,200 × 449 为基准的原卷参照范围。透明人物参照原画，包含遮挡补全和新动作，是艺术转译而非无损原画抠图。高清全卷仅供原卷对照，不作为超宽 GPU 贴图上传。

夜宴的“暗线”入口提供每折线索、提示和选择反馈；“识席间人”可查看可考人物的生平与关系。末折进入终章，回顾画意、南唐背景及人物结局。史籍叙事、研究推测和创作对白分别标明，出处可在每段下方打开。见 [史料校核](docs/hanxizai-history-notes.md)。

夜宴入席后会响起轻柔的原创筝笛意象配乐：五折各有旋律，随换折淡入淡出，翻阅人物笺和解谜时自动降低音量。右上角「配乐」（手机为扬声器图标）可关闭声音或调整音量，默认 28%，设置会保留。暂停、切到后台及归卷时停止播放；音色由浏览器生成，不依赖外部音频下载，也不作古曲或真实演奏复原的声明。

## 江山秋色图配乐

三个区域分别播放 `public/paintings/jiangshan-qiuse/music/` 下的溪桥行旅、山湖叠翠、江村秋色 MP3。入画时开启，Esc 暂停面板可调音量或静音，偏好自动保存。

音乐边界复用地图 ZONES：溪桥/山湖在 x=-112，山湖/江村在 x=74。每个边界两侧各 12 米使用位置驱动的等功率混音，快速折返不重播。音量变化约 0.8 秒收敛，离开区域后淡出并保存进度。首次从曲首播放，曲尾与曲首采用 2 秒交叠循环。实际解码后按 RMS 仅衰减较响曲目，避免跨区平均电平落差；不修改原音频。

暂停淡出并保存进度，续游渐入；人物对白气泡可见时降音；页面隐藏停止音源，归卷释放音频上下文。下载失败不阻塞游览，可在暂停面板重试。

## 卷轴音效与配乐设置

画卷一配乐控件位于入画和 Esc 暂停卡片内，可调音量或静音，点击续游回到画中。

入口展卷、收卷加入 Web Audio 合成纸绢摩擦与轻微木轴落定声。摩擦音量由 GSAP 中纸面展开和木轴转动的实际速度驱动，静止时无摩擦声，减少动态效果时随动画同步。首次点击可用卷轴后开启音频；动画结束、页面隐藏或进入画境时停止音源。浏览器不支持音频时仍正常展收卷。

## 独立人物试作

人物测试页已撤下。画卷一人物采用透明绘画素材：村妇坐姿织布、文士有不同面容且衣袖轻动、行旅在白塔旁的临江山坡土路上活动（仅供远观），近处楼阁平台保留两人，钓鱼船在离岸水域。原对白保留。

仕女试作素材保留在 `public/characters/song-lady/`，包含正、侧、背三视图；素材规格见[说明](public/characters/song-lady/ASSETS.md)。正式画境的人物图集位于 `public/paintings/jiangshan-qiuse/people/`。

画卷一新增四处诗画互动：溪桥文士、亭中文士、山上楼阁主人、钓鱼船中渔夫。靠近并看向人物时按 F，按心情选择诗词，生成当前视角诗画笺；定格截图作为毛玻璃背景，音乐继续播放，按 Esc 或“收笺续游”恢复游览。人物原对白保留，墙体及船棚遮挡时不触发。

画卷一两处瀑布的下游各有一艘可登小舟，船位避开落水点并检查水深与近岸落脚处。靠近可论诗人物时，按桥上、亭中、山上楼阁和渔船的具体情境显示水墨指引并淡出；登船、上岸保留底部操作提示，同一地点停留时不循环闪现。天空新增二十二只淡墨飞鸟，分远山两群和水陆游览区域上空的三群，沿固定弧线振翅与滑翔，诗画定格时同步停住。
